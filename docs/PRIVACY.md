# Publication boundaries

This repository is an anonymized engineering reference. It contains application
source, migrations and synthetic unit-test fixtures. It does not distribute a
client identity, customer export, filled agreement or business contract template.

Create operational templates and records privately through the application. Store
uploads and identity documents outside Git. Never copy production databases into
a public checkout. Tests build minimal documents in memory from synthetic data.

The source history has been filtered to remove document/export files, obsolete
identity assets and generated bytecode/static output. Original author timestamps
were retained; commit hashes changed as a consequence of filtering.

Run the repository privacy check before publication:

```bash
python scripts/check_public_history.py
```

It checks every reachable object for prohibited document formats and known secret
patterns. This is a preventive check, not proof that arbitrary free text is safe;
review changed text and images before publishing. Original company names must not
be added to a denylist committed into this repository. Supply any private extra
pattern through `PRIVACY_FORBIDDEN_PATTERN` when conducting a private audit.

Publishing sanitized source cannot erase third-party clones or previously cached
URLs. Those copies require separate owner/provider handling. No production data or
service is migrated by this repository.
